# 文件怪透明动作展示设计

## 目标

从 `assets/source/filemonster_source.mp4` 生成只保留文件怪主体的透明动作素材。桌宠必须完整展示动作，不显示原视频背景，不通过遮罩或界面裁切制造“已透明”的假象。

## 素材方案

- 对源视频逐帧提取文件怪主体的高质量 Alpha 蒙版。
- 对蒙版边缘做去杂色、羽化和时序稳定处理，减少白边、抖边和帧间闪烁。
- 沿用现有动作切片时序，输出对应的透明 VP9 WebM 文件。
- 额外输出透明静态 WebP，作为首次加载和无法立即解码时的占位图。
- 不用动画 WebP 替代主动画，因为当前动作状态依赖视频的播放、循环、定位和结束事件。

## 展示方案

- 视频容器按透明素材的有效画布比例展示，不拉伸主体。
- 视频使用 `object-fit: contain`，保证所有动作完整可见。
- 静止画布、拖放感应区和 Electron 窗口尺寸与新画布保持一致。
- 动作切换继续复用现有状态机；非循环动作结束后按当前规则回到待机动作。

## 失败与降级

- 如果某个动作透明素材不存在或解码失败，显示透明 WebP 占位图并报告素材错误，不显示旧的有背景视频。
- 素材处理失败时保留原文件，不覆盖现有动作文件。
- 全部新素材生成成功后再一次性切换资源清单，避免部分动作透明、部分动作带背景。

## 验收标准

1. 所有动作素材具有真实 Alpha 通道，透明区域像素可被工具检测。
2. 文件怪在每个动作的所有帧中完整可见，没有头部、手脚或道具被裁掉。
3. 透明边缘无明显底色残留，连续播放无明显蒙版闪烁。
4. 待机、拖放、工作、成功、失败和睡眠等动作能正常循环或结束并切换。
5. 页面背景透过视频透明区域可见，且不依赖近似背景色或 CSS 混合模式。

## 范围

只修改动作素材处理、资源引用和展示尺寸；不改动文件整理、回收、拖放判断及设置业务逻辑。
